Ping

Turn on notifications so reminders show up in the corner of Windows even when this window is behind others. Without them you still get an alert in this window and a sound.

Your save file needs one click to reconnect. Edge asks for permission again after a restart. Your data is safe in the meantime.

    Start typing to create a note. Markdown works, and it saves automatically.

    Notifications

    Install Ping as an app

    Install Ping as an app to get its own window and taskbar icon, and to be able to start it when you sign in to Windows. It also works offline.

    Ticket links

    Ticket IDs like DATA-123 in reminders and notes become links. Use {key} where the ID goes.

    Azure DevOps example: https://dev.azure.com/org/project/_workitems/edit/{num}. {num} is the number part only.

    Look and feel

    Mode

    Outlook

    Every reminder has an “Outlook” action. It downloads a calendar file; open it and click Save & Close in Outlook. Outlook then reminds you on this PC and your phone, even when Ping is closed. Interval repeats are included; for cron schedules Outlook gets the next run only.

    Your data

    Everything saves automatically the moment you change it, and stays saved when you close the window. It is kept on this PC only. Reminders pop up only while Ping is open, so minimise it rather than closing it. Anything missed while it was closed appears when you open it again.
